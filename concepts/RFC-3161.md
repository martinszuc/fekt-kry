# RFC 3161 — Internet X.509 PKI Time-Stamp Protocol (TSP)

**RFC 3161** definuje protokol pre vydávanie **dôveryhodných elektronických časových razítok** (*timestamping*) pomocou PKI.

**Účastníci:**
- **Klient** — posiela haš dokumentu (nie dokument samotný!)
- **TSA** (*Time Stamping Authority*) — dôveryhodná tretia strana; vydáva razítko

**Postup:**
1. Klient vypočíta $H = \text{Hash}(\text{dokument})$
2. Klient pošle $H$ + identifikátor haša TSA
3. TSA overí žiadosť, vloží $H$ + aktuálny čas do štruktúry a podpíše kľúčom TSA
4. TSA vráti podpísaný `TimeStampToken`
5. Klient uloží token spolu s dokumentom

**Čo časové razítko preukazuje:**
- Dokument **existoval** v danom čase (nie neskôr)
- Dokument **nebol zmenený** od vydania razítka
